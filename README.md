# Конфиги Forum Binder

Отсюда расширение Majestic Forum Binder берёт **официальные бинды** и **каталог конфигов**.
Пользователи ничего не получают автоматически: у них появляется значок «↑», а обновление
ставится только кнопкой на вкладке «Конфиги».

## Что где лежит

| Файл | Зачем |
|---|---|
| `index.json` | Каталог: какой файл — официальные бинды, какие конфиги показывать в каталоге |
| `configs/official.json` | Официальные бинды |
| `configs/*.json` | Конфиги каталога |

## Как обновить официальные бинды

1. В расширении: вкладка **«Конфиги»** → блок **«Поделиться своим конфигом»** → название «Официальные бинды» → **«Скачать файл»**.
2. Переименуйте скачанный файл в `official.json`.
3. На GitHub откройте папку `configs` → **Add file → Upload files** → перетащите `official.json` → **Commit changes**.

Всё. В течение ~5 минут (кэш GitHub) у пользователей появится «Доступно обновление».

## Как добавить конфиг в каталог

1. Человек присылает вам файл (он делает его той же кнопкой «Скачать файл»).
2. Загрузите его в папку `configs` (имя латиницей, без пробелов, например `state-seattle.json`).
3. Откройте `index.json` → карандаш (Edit) → добавьте строку в `items`:

```json
"items": [
  { "file": "configs/state-seattle.json", "name": "STATE Seattle", "author": "Ник", "description": "Кратко, что внутри", "binds": 40 }
]
```

Достаточно и просто `"configs/state-seattle.json"` — название и автор возьмутся из самого файла.
Чтобы убрать конфиг из каталога — удалите его строку из `items`.

## Важно

- Репозиторий должен быть **публичным** — иначе расширение не сможет прочитать файлы.
- Всё, что лежит здесь, видно всем. Не кладите сюда ничего секретного.
- Если в `index.json` ошибка (лишняя запятая и т.п.), в расширении будет «В файле ошибка JSON» — проверьте файл, например, на jsonlint.com.
